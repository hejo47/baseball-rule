## 3. 실제로 틀렸던 질문과 처리

- **질문:** "포스아웃 상황에서 공은 완전히 잡았는데 공이 땅에 닿아 있으면 아웃인가요?"
- **배포본의 틀린 답:** "아니오, 정규 포구가 아니라 볼 데드"
- **정답:** 아웃. 포스 아웃은 공을 확실히 쥐고 베이스를 밟으면 된다(5.09⒝⑹, 정의-75 태그).
  "땅에 닿기 전에 잡아야 한다"는 플라이 이야기다.
- **처리:** 용어 정의 함께 넘기기 + 5.09⒝⑹ 사람 말 설명. 고친 뒤 배포본이 세 가지 질문 모두 "아웃"으로 답했다.
- **결정:** 틀린 질문마다 하나씩 고치지 않는다. 틀린 답 신고를 모아서 **같은 유형이 반복될 때만** 고친다.
  포스 아웃 설명은 남겨 두기로 했다.

## 4. 알게 된 것

### 답변 모델 (NVIDIA 무료 API, gpt-oss-20b)

- 이 컴퓨터(한국)에서는 몇 시간 동안 무응답이었고, 같은 시각 배포본(Vercel)은 정상이었다.
  모델과 키는 같다. 요청 위치에 따른 장애로 본다.
- **로컬에서 답변이 안 나와도 배포본이 죽었다고 단정하지 말고 배포본에 직접 물어본다.**
- 그래서 오늘 바꾼 것들의 `eval:answer`(답변 채점)는 아직 못 쟀다.

### 선수 데이터는 자동으로 가져올 수 없다

- **KBO 공식:** robots.txt에 "사전 승인 없이 자동 수집 금지". 이용약관 제14조 차항은 자동 수단으로
  선수 통계 등을 대량 반복 수집하는 것과 재배포·다른 플랫폼 연동·2차 가공을 금지한다(사전 서면 동의나
  KBO 공식 API가 있으면 예외). 제17조는 상업적 사용 금지(사전 동의 시 가능).
- **네이버 스포츠:** 검색엔진 외 차단. **스탯티즈:** 봇 차단.
- **AI가 읽어서 DB에 넣는 것도 자동 수집이라 안 된다.**
- 저작권법 제93조: 데이터베이스의 개별 소재는 보호 대상이 아니지만, 반복적·체계적으로 가져가면
  상당 부분 복제로 본다. 제7조: 사실의 전달에 불과한 시사보도는 보호받지 않는다.
